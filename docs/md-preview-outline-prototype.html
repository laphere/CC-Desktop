双栏同面卡

大纲卡与正文卡同用 --panel surface（radius 12 + shadow），gap 12 并排；正文版心（92%、上限 1240px）照旧居中，折叠后自动回到满宽。

宽度阈值与迟滞

≥1120 显示、<1080 折叠、>1120 恢复，40px 迟滞 + 80ms 防抖（照左栏 980/1020 模式）；只自动恢复「被自动收起」的那次，手动关闭后拉宽不自动开。

手动开关

控件行加 PanelLeft 图标按钮（md 态专属），手动态 module 级记忆：本次运行内换文件、关开浮层都保留，不写 config。

点击跳转与 scrollspy

点大纲平滑滚到标题（顶部留 44px 呼吸）；正文滚动以「卡顶 + 96px」参考线定 active，大纲内 active 项居中跟随；位置全用实时 rect，图片加载移位不失效。

空大纲兜底

文档无标题时不渲染大纲面板与开关，布局与现状完全一致；html 预览完全不参与，iframe 态零改动。

折叠动画

抽屉模式：width 240→0 + 淡出，--dur-slow + --ease-emph（240ms），内层定宽不重排；单文档重折行成本可接受（与会话左栏禁 basis 动画的场景不同）。

实施落点：src/components/FilePreviewOverlay.tsx（大纲提取 / scrollspy / 开关 / 宽度自适应）+ src/styles.css（.fp-outline* 追加在 fp-* 块后）。阈值常量 OUTLINE_COLLAPSE_BELOW = 1080 / OUTLINE_EXPAND_ABOVE = 1120，参考线 96px、跳转留白 44px、大纲宽 240px——实施评审时可再调。大纲收集 h1–h6（演示文档只到 h4），缩进按「层级 − 最小层级」clamp 0–4。
