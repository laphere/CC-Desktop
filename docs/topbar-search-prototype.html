顶栏搜索（项目 + 会话）· UI 方案

顶栏搜索按钮改为项目 + 会话搜索（路径匹配移除）。入口与开合机制不变：点顶栏 🔍 展开左栏顶部搜索框，Esc / 再点收起。输入后：项目列表原地按项目名过滤；其上方出现「会话」结果区（跨项目，置顶区搜索期间让位）——标题/摘要命中约 1 秒先出，随后全文扫描（正文 + 工具调用）把内容命中的会话带高亮片段并入。下框为可交互演示（虚构数据），右上角可切换 app 深浅主题。

演示数据为虚构（项目名取自真实工作区）。操作：点顶栏 🔍（或下方示例词）唤出搜索框；注意搜索时置顶区让位、项目名过滤仍生效；点会话命中行在右侧打开只读会话页。

三层匹配口径

项目按项目名匹配（路径不再参与）；会话按标题 + 摘要快档匹配，随后全文匹配正文 text 块与工具调用输入（跳过 thinking / tool_result）。搜函数名、报错信息这类正文关键词也能找到会话。

两段式节奏

输入 300ms 防抖后：快档扫描全部会话首尾 64KB 元数据（约 1 秒）先出标题命中；全文扫描继续在后台跑，命中带片段陆续并入，状态行「正在搜索会话内容…」→「N 个会话」。关键词改动即作废上一轮（世代号）。

置顶区让位

搜索期间置顶区隐藏，避免与全局会话命中重复显示；已置顶会话照样参与召回（试「拖拽」「供应商」，图钉呈 accent 色提示它同时在置顶区）。收起搜索即还原。

命中行形态

复用 SessionRow：项目名徽标 + 标题（关键词高亮）+ 时间摘要行 + 片段行（全文命中才有，约 60 字符上下文、两行截断）。顺序保持 mtime 倒序，不按命中数重排。

点击命中 → 打开会话

复用现有 continueSessionTab：打开只读会话页（不启动进程）；全文命中的会话定位并高亮首个命中（复用 jumpTo 跨分页链路）。项目行照常点击展开，其会话列表不参与过滤。

范围与上限

搜索范围 = 左栏可见项目（扫描 ∪ 手动添加 − 排除清单），与列表口径一致；结果最多 50 个会话（沿暂缓方案口径）；单会话命中上限沿用 MAX_SEARCH_HITS=200。

实现约束：图标全部沿用 Icons.tsx 既有 SVG（零新增图标）；无新按钮类（清除复用 .search-clear）；高亮 <mark> 取 --accent-soft / --accent 主题变量，深浅两套自动适配。后端新增一个 IPC（快档 / 全文两档复用同一扫描核），前端复用 continueSessionTab / SessionRow / 现有搜索框开合机制。
