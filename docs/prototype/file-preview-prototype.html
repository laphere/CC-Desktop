路径 chip：无图标前缀，点状虚线常显

正文流里给路径加图标太吵。可点性靠「点状虚线」这个最轻暗示表达，hover 变实线 + accent 色。保持 .md-body code 彩色字无底的定稿不动，chip 只是叠加下划线。

手势三件套

点击 = app 内预览（安全，首选）；右键 = 文件菜单；Ctrl+点击 = 系统默认程序打开——与现有外链 Ctrl 手势同款。title 提示「点击预览，右键更多操作」。

菜单条目按扩展名裁剪

「在浏览器中打开」只对 html 显示（md 的默认程序多半是编辑器，不算「浏览器」）；「在资源管理器中显示」用 showItemInFolder 定位并选中文件，不是打开父目录。复制绝对路径常驻。

预览浮层 = lightbox 同款

全屏深遮罩（z 950），控件行让位自绘标题栏（top: 44px + 12px，WCO 系统按钮之下）；Esc / 点遮罩 / 关闭钮收起；md 与 html 两态，按扩展名分派。

md 预览复用会话 markdown 管线

marked + DOMPurify + 同一套 md-body 样式与单色代码配色，预览观感 = 会话观感。预览内容里的路径 chip 同样可点——md 文档里引用别的文件可以级联预览。

html 预览 = 沙箱 iframe

srcDoc + sandbox="allow-scripts"：脚本可跑（原型可交互、可切主题），但 iframe 是 opaque origin，拿不到父窗与 IPC 桥——渲染进程安全红线不破。localStorage/sessionStorage 注入内存 shim 防脚本炸掉。引用本地相对资源的 html 不保证完整，菜单里「浏览器打开」兜底。

不存在 / 超限的兜底

点击先 preview_stat：不存在 → toast「文件不存在」，不炸浮层；实现层还有扩展名白名单（md/html/htm）与 10MB 上限，白名单外路径不做 chip、点击提示不支持预览。

入口三处的形态差异

消息 chip：点击预览 + 右键菜单；Write/Edit 卡头：路径文本可点预览，卡头右侧 hover 浮现 ⋯ 菜单钮；变更文件抽屉：条目保留「点击跳转消息」不变，右侧 hover 浮现预览钮 + 右键菜单。
